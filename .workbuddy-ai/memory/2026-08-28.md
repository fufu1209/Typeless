### 拆分踩坑清单（下次直接照做）
1. **SwiftPM @main 互斥**：可执行 target 有 main.swift 时，顶层代码与 @main 不能共存。
   单文件能蒙过，多文件必报 `'main' attribute cannot be used in a module that contains top-level code`。
   → 实现搬到 AppMain.swift，main.swift 只留一行调用；入口 enum 去掉 @main，
     `static func main()` 显式标 @MainActor
2. **切分带属性**：`// MARK` 前的 `@MainActor` 会被留在上一段尾部 → 回移到下一段开头
3. **存储属性不能进 extension**（lastSavedStateData、6 个权限探测缓存）→ 移回主类体
4. **区间重叠会重复声明** → 切完必须按「方法签名」查重
5. **private/fileprivate 跨文件不可见**（`private extension String.ifEmpty`、
   `private extension JSONEncoder`）→ 提升为 internal
6. **切割后务必先合成单文件编译验证**，确认内容无损再正式拆
7. `Color.tertiary` 是 ShapeStyle 不是 Color → 用 `Color(nsColor: .tertiaryLabelColor)`
8. SwiftUI 尾随闭包后不能再跟标签参数：`SettingsCard(...) { content } footnote: {}` 编译不过，
   footnote 必须是 String 且放在尾随闭包之前
